# 输出模板（AI agent 每次分析必须按此格式输出）

> 铁律1：主方向与对冲必须标注概率权重，绝不并列。
> 铁律2：首发未出 = 半成品，必须在首发状态行明示。
> 铁律10（定价差异审计）：输出顺序固定为——先报市场定价，再报模型概率与差值，最后做信息差审计。
> 铁律11（未反映举证）：每条信息差必须回答"为什么市场还没定价"，答不出 edge 按 0 处理。

### 1b. 信息差审计（铁律10/11）
- 信息差清单：{逐条列出"市场可能未充分反映"的信息}
- 未反映举证：{每条回答"为什么市场还没把这条打进赔率"；答不出的条目标注"默认已定价，edge=0"}
- 无可举证的信息差时，本节直接写："无信息差，edge 视为模型噪声"

### 2. 主方向与对冲（概率权重）
- **主方向**：{方向}（{概率}%）
- **对冲**：{方向}（{概率}%），对冲成本：{说明，如"双选降赔率约x%"或"单吊对冲=放弃主方向，不建议"}
- 极端值提示（铁律6）：{如无则写"无"}

### 3. 交叉验证摘要
- 事实源：{账号/媒体 + 日期 + 取用的事实点，1-2 行}
- 分歧：{如有，写裁决过程；无则写"无实质分歧"}

### 4. 资金信号（铁律3）
- {某方向}赔率 {初盘} → {现盘}，降幅 {x}%（>5% 则标为最高权重信号）

### 5. 结论
{推荐方向 / 观望（0元），一句话}

### 6. 纪律账（每次推荐必附）
- 本注：{x} 元（占本金 {x}%）
- 累计盈亏：{±x} 元
- 距 7000 元红线：{x} 元
- 置信度：高 / 中 / 低

## 附：固定 JSON 输出块（tracker.py 自动解析）

每次分析输出末尾必须附带以下 JSON 块（字段固定，缺失用 null）：

```json
{
  "match": "桑托斯 vs 弗拉门戈",
  "league": "巴甲",
  "market": "胜平负",
  "pick": "弗拉门戈胜",
  "prob": 0.54,
  "hedge": {"pick": "平", "prob": 0.23},
  "confidence": "中",
  "stake": 0,
  "market_odds": 1.80,
  "odds_snapshot_at": "2026-10-09T00:30:00+08:00",
  "lineup_status": "半成品",
  "analyzed_at": "2026-10-09T00:35:00+08:00",
  "model_version": "penaltyblog-1.13.1/dixon-coles",
  "data_date": "2026-10-09",
  "closing_odds": null
}
```

字段说明：
- `market`：胜平负 / 大小球 / 让球
- `lineup_status`：只能是"成品"或"半成品"
- `closing_odds`：赛后由 settle.py 回填收盘赔率（市场平均 Avg 列），用于 CLV 计算
- 解析命令：`python scripts/tracker.py add-from-json analysis.json`
